# ریاضی و آمار برای Quant Developer

کد و داده‌های دوره رایگان **«ریاضی و آمار برای Quant Developer»** از [Quant Academy](https://quantacademy.ir).

۱۴ درس: احتمال، توزیع‌ها و دم پهن، برآورد و آزمون فرضیه، همبستگی و رگرسیون، سری زمانی، حرکت براونی و فرایند پواسون، جبر خطی، بهینه‌سازی و مونت‌کارلو؛ همه با Python و مثال بازار.

📚 متن درس‌ها: https://quantacademy.ir/courses/quant-math/

> داده‌های این دوره **شبیه‌سازی‌شده** هستند، نه قیمت واقعی بازار.
> آموزشی است و توصیه سرمایه‌گذاری نیست.

## اجرا روی کامپیوتر خودت

```sh
git clone https://github.com/quantacademyir/quant-math.git
cd quant-math
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/
```

نوت‌بوک‌ها داده را از آدرس GitHub می‌خوانند. اگر GitHub یا اینترنت در دسترس نبود، فایل‌های پوشه `data/` را کنار نوت‌بوک بگذار و آدرس داده را در سلول مربوط به مسیر فایل تغییر بده.

## ساختار

| مسیر | محتوا |
|---|---|
| `notebooks/` | نوت‌بوک هر درس |
| `data/` | داده شبیه‌سازی‌شده |
| `scripts/` | ساخت دوباره داده |
